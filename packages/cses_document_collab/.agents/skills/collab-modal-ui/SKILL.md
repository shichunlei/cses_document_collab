# 协同包弹窗开发

将弹窗展示统一到包内公共组件，业务草稿、保存、删除、协同和编辑会话仍由原业务层负责。用户的新要求优先于本文记录的默认样式；只修改本次需求涉及的范围。

本文路径除另有说明外均相对 `packages/cses_document_collab/`。先遵循适用的 `AGENTS.md`；涉及 BlockCraft 块行为时，按根规范核对桌面配置仓库的 latest、声明/锁定/安装及随包文档。不能核对时记录原因，不将历史版本或旧测试当成本轮结论。

## 先定位职责，再选择公共入口

先读 [公共展示入口](../../../lib/src/ui/modal/collab_modal.dart) 及 `lib/src/ui/modal/` 中所涉组件的独立实现和已有调用方。梳理当前入口、取消/确认结果、权限、焦点、保存时机和控制器所有权，再决定需要修改的展示层。不要在统一样式时移动或重写业务事务。

| 展示形式 | 展示入口 | 内容外壳 | 适用情形 |
|---|---|---|---|
| 底部弹窗 | `showCollabBottomSheet<T>` | `CollabBottomSheet` | 媒体来源、图标、封面位置、绘图源码、块操作等 |
| 居中弹窗 | `showCollabDialog<T>` | `CollabDialog` | 图片属性、题注、资源属性、文字链接、导入确认等 |
| 锚点菜单 | `showCollabPopover<T>` | 函数内自动创建 `CollabPopover` | 编号、代码名称/语言、表格行列、绘图视图/类型/模板 |

复用 `CollabModalHeader`、`CollabModalActions`、`CollabModalField`、`CollabModalSegments<T>`；不要为了某个新菜单再造圆角、标题、按钮或定位系统。现有组件不足时，优先加保持旧默认值的可选配置，例如 `showCollabPopover(width: 220)`，并检查消费者。

菜单行复用 `CollabMenuRow`，开关行复用 `CollabSwitchRow`，均由 `Row` 自定义布局；本包源码、测试夹具和示例禁止使用或包装 Flutter `ListTile`、`SwitchListTile`、`CheckboxListTile`、`RadioListTile` 等系列组件及其 SDK 主题配置。`CollabSwitchRow` 只有开关本体可切换，标题、说明、图标与空白区域没有行级点击事件，也不提供整行回调。菜单密度由 `CollabModalTheme.compactList` 传递，保留51/42逻辑像素最小高度并允许大字换行增长；禁用态、键盘和无障碍语义由共用行处理。

公共组件每个 Widget 独立成文件，私有 State/Painter 等专属实现随所属组件维护；`collab_modal.dart` 只保留三类展示函数及私有定位，不增加组件聚合导出。菜单行、主题、颜色、头部、操作区、字段、分段选择器和三类外壳分别导入对应 `collab_*.dart`。卡片外框/标题栏/锁标、颜色/表情选择器、缓存图片、媒体来源面板与进度、公式/绘图/分割线和链接/网页预览等共用展示也放在同目录；只借用业务模型和回调，不导入 `editor/`。编辑器命令、选区、权限、操作会话及专属块适配器仍在业务模块。

内部跨目录使用精确 `package:cses_document_collab/src/...` import。当前公共弹窗是包内实现；宿主仍只能使用包的公开入口，不为宿主直接使用这些内部 Widget 扩大导出。

## 已确认的展示规则

- 天气设置与日期使用同款样式切换：居中预览、左右箭头循环7种布局，名称位于预览下方；预览/箭头/名称固定在公共底部面板header，短视口压缩预览，其他设置独立滚动。切回原样式恢复原宽高及缺省字段，无变化应用正常关闭且不新增历史。取消/下滑关闭丢弃草稿，修改应用仍为一次事务，锁/撤权/远端冲突规则保持。回归见`weather_bottom_sheet_test.dart`与`collab_weather_test.dart`。

- 日期设置使用公共底部弹窗；标题下的日期预览居中并固定，左右按钮循环切换12种样式，名称显示在预览下面。预览、箭头和名称不随设置区滚动；短视口/键盘场景压缩预览。取消/应用固定底部，其他格式/字体/字号/边框按约束分行并独立滚动。草稿应用一次提交，取消和下滑关闭不写入；切回原样式/格式恢复原尺寸，字号按内容倍率换算；锁、撤权及远端变化后旧草稿仍须重开。

- 字间距（Aa）与行间距（段落布局）沿用固定返回/默认项、横向滚动数字预设，选择即时生效并保持菜单与键盘。字距按em展示并清除旧CSS字距，行高按倍数作用于正文段落；混合值不误标默认。配置禁用不显示，撤权后重开才恢复。对应回归`editor_spacing_test.dart`，不叠加底部弹窗。

- 字号选择使用Aa行内横向子菜单，左侧返回和“默认”项固定，只滚动字号数字；选中即时生效并回显，菜单与键盘保持。划词格式面板复用同一子菜单，不另叠字号底部弹窗。保留实例字号配置、连续选择的独立历史、撤权后旧菜单失效及会话切换保护。“默认”同事务清除局部`t:px`和旧`s:fontSize`覆盖，继承段落或标题，不清除其他字样；混合字号不能误选中默认。

- 从 `CollabModalColors.of(context)` 取色；主色、背景、文字、边线和危险色均支持亮/暗主题。细节默认值见实现，必要时查 [场景与决策参考](references/modal-decisions.md)。
- 表单的主要确认操作放在右侧 `actions`；需要左侧删除/移除时使用 `leadingAction`。图标与高亮表情的移除在底部左侧，与右侧完成/保存同一操作栏；窄屏大字允许公共按钮组换行。
- 独立公式卡片移除三个点，整卡点击打开统一编辑面板。新建只有源码、预览和取消/创建，不提供块操作；编辑时预览下方直接排列锁定、复制段落链接及下方插入，删除公式以trash2图标加文字固定底部左侧，图标与文字共用danger色，取消/保存固定右侧，不在内容区重复删除。锁定时禁用输入并隐藏插入、删除和保存，保留复制、授权解锁及继承锁定位；锁变化后须重开。复制保留草稿及面板，带草稿执行锁定/下方插入先选择保存并继续、放弃修改或取消；命令完整退场后核对身份/权限/快照执行。行内公式保留原交互，添加入口及输入弹窗使用LucideIcons.omega（Ω），独立公式块继续使用sigma（Σ）。
- 删除/移除的可用文字与图标都用 `danger`，禁用态沿用主题。操作菜单中的删除使用基于 `Row` 的整行 `CollabMenuRow`；不要把所有删除动作都强行改为底部按钮。
- 标题栏说明由 `CollabModalHeader.subtitle` 统一单行、省略号、禁止软换行；传入完整链接，不截短原始业务值。不把副标题规则擅自套到允许换行的主标题。
- 链接操作里的链接/卡片/嵌入视图选项与上方资源操作之间加浅色分割线；只有视图选项存在时才显示该分隔。
- 分页符通过点击整条虚线/文字标记打开公共块操作面板，不在右侧显示三个点；只读保留标记并禁用点击，沿用公共菜单的身份、权限及失败保护。分页符和分割线在块锁生效时保留公共无标题卡片，不添加右侧更多按钮。分割线无论是否锁定都通过整条点击打开统一样式面板；设置下方直接排列锁定、复制块链接、下方插入，删除固定左下、完成固定右下。锁定时禁用样式修改并隐藏下方插入及删除，保留复制和授权解锁；本人在当前面板解锁可恢复编辑，远端锁变化/撤权后的旧面板必须重开。新建先在同款面板暂存外观，完成后才一次插入；取消不写正文/历史。
- 公共块操作面板的头部默认按块类型显示名称及对应 Lucide 图标（图片、视频、代码块、高亮块、音频、附件、公式、代码绘图、链接等），不再显示“块操作＋ellipsis”。未识别的新类型使用“内容＋file”；卡片上的三个点触发按钮保持原样，调用方仍可分别覆盖标题或图标。
- 各卡片的公共更多及网页独立链接菜单在正式文档已配置宿主`buildParagraphLink`且节点有稳定ID时提供“复制段落链接”（link图标）；保留原资源“复制链接”。复制不写正文/历史、不恢复键盘，锁定块可复制，沿用原菜单预览显隐和权限/快照/会话保护；草稿不生成分享链接。
- 仅保留卡片自身已有更多按钮；锁装饰层不再为段落、标题、引用、待办/有序/无序列表、表格等正文增加更多入口，选中或锁定也不显示，暂不新增替代操作。普通正文同时暂不显示锁标和占位，实际锁定保护保持，卡片锁提示沿用原规则。
- 公共更多菜单的“复制内容”仅在高亮块保留，代码绘图保留复制入口并显示“复制代码”，其他块不显示；沿用原锁服务与账号可用条件，保留独立“复制代码”、资源链接、段落链接和会议号等专用复制操作。
- 网页卡片/网页嵌入/Figma/掘金的独立链接菜单同公共面板提供锁定/解锁与继承锁定位，使用CollabBlockLocks权限；锁定时保留打开/复制，隐藏修改/删除/插入/切换视图，锁或权限变化使旧菜单失效。附件及标准卡片共用CollabCardLockOverlay，外边距在覆盖层外、圆角裁切在内容内，锁标位于实际外框top/right=-5，不挪动更多按钮。
- 会议、任务卡片的快捷操作通过 `CollabBlockMoreButton.menuTitle/menuIcon` 指定头部，分别为“会议操作＋users”和“任务操作＋listTodo”；保留各自的专用头部。配置只影响弹窗头部，保留原菜单命令与更多按钮。
- 编号及绘图视图、类型、模板的锚点菜单使用 `width: 220`；其他浮层维持既有默认宽度265，除非用户要求调整。编号和视图这类持久选项显示当前勾选；类型插入/模板替换是动作，不虚构持久选中状态。
- 图标选用当前已安装的 `lucide_icons_flutter` 声明，不恢复SDK图标。下方插入统一 `LucideIcons.listEnd`。Figma/掘金仍使用Lucide通用设计/文章图标，用户已决定暂不引入品牌Logo；不要当成待完成迁移。
- 封面位置仅在图片内上下拖动，下面显示双向箭头和“按住图片上下拖动，调整封面位置”；不恢复滑条或百分比。保存才提交，取消不写入。

## 布局中容易复发的问题

1. **短内容使按钮下方出现大空白**：`expand: true` 时正文必须填满剩余高度，公共外壳已使用 `FlexFit.tight`；非展开使用 loose 按内容收缩。不要改全局固定高度或在尾部补占位来掩盖问题。
2. **键盘与安全区叠加**：底部外壳已处理 `viewInsets.bottom`、安全区和正文滚动。业务内容不要重复添加键盘避让、重复 SafeArea 或另一层无界滚动。
3. **操作区宽度不均**：公共操作区让左侧按自然宽度且不超过一半，右侧用剩余空间贴右；不要用两个等宽 Expanded 人为增大空隙。
   表情等自带惰性目录的内容可使用`CollabBottomSheet(scrollBody: false, expand: true)`取得有限正文高度，由选择器管理滚动；搜索和底部Tab固定，单一分类列表与Tab双向联动，不按Tab筛除分类；外部移除/完成操作仍归公共操作栏。其他消费者保留默认外壳滚动，不嵌套两个纵向视口。定位使用缓存行号和统一行高，手动拖动可接管动画，滚动只更新Tab，避免每帧重建全目录或扫描渲染对象。远距定位仅让目录短暂淡出、从目标附近滑入，搜索/Tab/操作栏保持；中断时恢复不透明度并使旧任务失效，过渡中不提交表情。
4. **下拉出现在整行另一端**：用按钮/序号自身的 `Builder` 上下文作为锚点，避免传整行或整卡的 context；沿用公共定位的上翻和屏幕/键盘限幅。
5. **五项菜单在低高度溢出**：给类型/模板等较长内容增加 `SingleChildScrollView`，固定公共菜单标题/关闭入口；不要让五项 Column 撑出约束。
6. **模拟尺寸和截图误判**：测试中的 MediaQuery 尺寸要与逻辑画布一致；系统底部区域需区分 padding/viewPadding，键盘另设 viewInsets。普通 Widget 测试默认字体不代表真实中文排版。

这些是现有实现的约束和已复现问题，不意味着所有新弹窗都要新增自定义布局或一组同构测试。

## 保留业务与编辑器契约

- 三个展示函数均等待 `route.completed` 后返回。不要退回裸 `showDialog`、`showModalBottomSheet` 或默认 PopupMenu 来绕过公共样式；也不要在退场结束前恢复正文输入或提交下一层弹窗。
- 展示函数只管理路由/主题，不替代 `runEditorHeaderAction`、选区保存、权限撤销或上传取消。保留原业务会话边界；调用后按场景重新核对 mounted、编辑器销毁、稳定节点身份、源内容/属性快照、宿主会话和权限。
- 对已有“撤权后重新授权仍失效”的会话保持原规则，不能简化为最终时刻 `editable == true`。远端删除、换源、重排或草稿冲突沿用原拒绝/重载机制。
- 控制器、监听、上传 CancelToken、播放器及平台视图继续由原创建方管理；公共外壳不接管或提前释放借用资源。避免重复菜单和重复提交，异步失败必须在有效业务边界记录并提示。
- 将移除按钮从选择器内容搬到外部操作栏时，原选择器内部的忙碌和异常捕获不会自动转移；补齐对应边界，保持同一字段事务、撤销和失败留在面板的行为。
- 共用媒体/链接菜单或块菜单已经有插入、删除入口；修改前核对完整命令清单，避免视频漏删、删除提及样式分叉，或重复暴露同一删除动作。仅有图标/菜单入口不算完成块能力适配。

## 验证与交付

按实际改动选择 [场景参考](references/modal-decisions.md) 中的目标测试，复用现有用例；新增行为或已复现的布局回归才补有意义的测试。仅装饰图标或颜色调整不机械增加镜像测试，也不重跑无关原生构建。

在包目录执行：

```sh
dart format <本次修改的手写Dart文件>
flutter analyze --no-pub <目标文件及必要消费者>
flutter test --no-pub <相关测试文件> --reporter expanded
git diff --check
```

沿用文件既有格式行宽，避免全仓格式化。接口、导出或名称/路径变化时，按根规范补充消费者验证和旧名检索；每个触达的 Dart 声明同步 DartDoc。纯 skill/文档修改只做结构、路径和 diff 校验。

布局变更优先覆盖真实受影响情形：320/390窄屏、大字、横屏/键盘、短/长内容、安全区、滚动时头尾固定；业务变更覆盖取消、确认、重复点击及实际受影响的权限/远端/历史路径。已有检查通过后，不无理由扩大回归。

需要截图时，`test/collab_modal_test.dart` 支持 `COLLAB_MODAL_PREVIEW_DIR` 和可选 `COLLAB_MODAL_PREVIEW_FONT`，可输出真实 Flutter PNG；普通测试不要硬依赖本机字体。共享外壳截图、交互式 HTML 设计稿和真机验收是不同证据，不能互相代替。不要把历史截图当作新布局验收。

交付说明实际改动、运行结果及未验证范围。涉及块支持范围或限制变化时，同步仓库 `docs/block-adaptation.md`；历史过程见 `docs/verification/modal-ui-20261017/modal-ui-20261017.json` 和 `modal-delete-actions-20261017.json`，它们不是后续任务自动通过的证明。后续明确改变上述产品规则时，同步更新本 skill 的对应条目和参考，不累计互相冲突的“最终规则”。
