## 行内与通用链路

- 正式普通正文支持行内公式，以及用户/会议/任务/文档四类提及；代码块和题注不是完整行内对象支持区。
- 用户提及已有宿主选人/头像/点击、原子编辑及历史，但对象身份剪贴板、拼音/首字母搜索、待办参与人联动仍有缺口；会议/任务/文档提及缺实体搜索选择及部分业务编辑。
- 桌面的行内日期、天气、人员、形状、艺术字不能从JSON本地渲染推断正式同步已支持。Rust `inline_embed` 只识别LaTeX和上述提及；不支持对象会保护所在段落，其他段落可继续编辑。
- 非空 `bc:revisions` 当前使正式文档仅预览；修订审阅没有接入移动编辑。未知块、异常容器或未适配行内对象同样受保护，保留原数据不等于功能支持。
- 正式文档与SQLite草稿已接Rust选择性历史，不能沿用旧文档“远端改字一律清空历史”的总述。远端贡献、锁、权限和结构冲突仍可能拒绝某次Undo；纯内存本地编辑仍使用AppFlowy历史。跨事务IME合组、对象/多格选区恢复、跨启动个人历史及大文档性能尚未完整验收，见[现行历史实现](../selective-undo-prototype-20261022/frb-editor-history.md)及[修复](../selective-undo-prototype-20261022/review-fixes.md)。
