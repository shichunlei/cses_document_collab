# 日期块三项修复与底部设置面板

日期：2026-10-25。先修复审查R1/P1、R2/P2、R3/P2并通过原三条反例，再迁移日期设置为公共底部弹窗。

## 修复

1. **R1：绘制安全。** 日期模型增加只读边框解析：正式九种外观和旧0～3px实线可显示，未知/异常值展示为无边框；原props不改写。点线画笔另有最多2048次路径描边预算和最小派生步长，避免异常微小宽度造成无实际次数上限的UI循环。
2. **R2：保持作者尺寸。** 重选已选样式/格式不产生草稿或几何写入；来回预览后最终切回原样式/格式时恢复原宽高及字段缺失状态。只有实际样式变化使用默认框，单独格式变化保持原宽；不让中间预览污染最终持久化与历史。
3. **R3：字号倍率。** 根据保存宽度与当前默认框推导内容倍率，控制数字按显示字号回显，写回先除以内容倍率，设计值保留两位小数并沿用稀疏存储。手机视口适配缩放不参与共享字号；无效倍率和溢出结果有读取/写入保护。

原336×289.504台历重选后保持原尺寸、无多余历史；2倍卡片选择显示字号32时保存设计字号16；原`1e-320px dotted`导入反例可安全绘制且保留原字段。

## 底部面板

- 日期入口改用`showCollabBottomSheet`和`CollabBottomSheet`，不再引用Dialog入口或外壳。
- 固定标题、取消/应用，中部独立滚动；日期预览约束为160逻辑像素高度，不随桌面保存的大尺寸占满菜单。
- 12种样式、格式、字体、字号与边框选项复用公共分段组件，按可用宽度/系统字号分行。390宽默认为4列样式，320大字相应减少列数，避免截图中的竖排拥挤。
- 草稿应用仍为单次事务；取消、下滑关闭不保存；原锁/撤权/远端变化后的失效保护继续有效。
- 同步包内弹窗skill、场景参考、README和适配表。日期仍为部分支持；浮动定位、复杂容器及其他已列限制未扩大验收。
