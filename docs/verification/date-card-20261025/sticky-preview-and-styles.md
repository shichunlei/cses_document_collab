# 日期预览居中吸顶与左右切换样式

日期：2026-10-25。

## 实际变化

- 日期预览、样式切换按钮和样式名称移到公共底部面板的固定`header`，下方设置继续在独立滚动区内。
- 预览两侧使用当前安装Lucide 4.0.1的左右箭头，按桌面目录顺序循环切换12种样式；首项向左可到末项，末项向右可回首项。
- 当前样式名称居中显示在预览下方，并提供读屏实时更新语义；原多行样式选项区移除。
- `CollabDateCardVisual`增加可选`alignment`，默认仍为`Alignment.centerLeft`。设置预览传入`Alignment.center`，同时作用于外层布局和实际缩放绘制，避免只居中容器、卡片本体仍偏左。
- 常规预览160逻辑像素高，短视口/键盘时压缩为80或32，以保留标题、样式名、操作区和设置滚动空间。
- 箭头只修改原有本地草稿。取消/下滑不写入，应用仍为单次事务；循环回原样式保留原尺寸，不增加空历史。失效或保存期间按钮禁用。
