# 日导向恢复文字格式菜单

日期：2026-10-23。按用户要求保留离线日导向的文字颜色、背景颜色、五种对齐、H1～H6、上下角标与既有文字操作。实现位于宿主 `example/lib/src/daily_guidance/`；共享包只增加通用排版入口和可选能力配置，无日导向栏目、人员或提交业务。

## 完成范围

- T菜单增加H1～H6，保留正文、有序/无序/待办列表；菜单可横向滚动。
- Aa菜单保留加粗、斜体、下划线、删除线，恢复行内代码、文字色、文字背景色、字号与互斥上下角标。
- 排版菜单提供左/中/右/两端/分散对齐、增加/减少缩进及块背景色。宿主栏目显式授权同父扁平列表缩进，仍不允许跨栏目或真实嵌套；文字段落保留既有8级/兄弟约束，列表沿用0～6级规则。
- 编辑与预览复用标题/字符排版和对齐实现。字号改变时列表标记按首行高度居中；分散对齐复用宿主列表标记。
- 类型转换通过显式通用属性白名单保留业务行身份与完成状态；宿主包装原生正文，保留都来帮/领航员/任务前缀及原生node.key。旧草稿v1/v2兼容，版本仍为2，含隐藏栏目的数据校验和原子保护保持。非法/缺失或超出1～6的日导向标题级别拒绝读取，不回退覆盖为空草稿。
- 修复AppFlowy本地fork中待办行无条件覆盖局部样式的调用：将完整TextSpan交给既有排版回调，保留字号及字符装饰；来源仍为仓库原有AppFlowy 6.2.0 fork，许可证未改变。该补丁为通用文字渲染修复。

上下角标沿用共享编辑器现有OpenType字体特性；具体字形依赖设备字体。本轮未扩展字体资源、图片插入或下一段样式等其他业务能力，也不接入WS提交。JSON草稿仍可保留这些本地节点与样式，业务提交格式设计见已有[JSON分析](json-submit-analysis-20261023.md)。
