# 键盘菜单三项审查问题修复

日期：2026-10-23。对应[前轮审查R1～R3](../offline-journal-20261022/toolbar-list-review.md)，保留原失败记录，不追溯改写审查结论。

## 修复

### R1：原生选人会话永久失效

页面为每次原生选择持有独立权限信号，合并编辑器权限和页面/账号/企业/会话状态。Common身份字段没有变更通知，因此沿用既有组织选择器的200毫秒采样，并在返回时同步核对；一旦观测失效即闩锁，不因原身份恢复而重新启用面板或接收旧结果。账号失效同时冻结旧正文，通用模态也不能恢复旧输入连接。

采样在取消、确认、失效和页面销毁时停止；借用的原权限监听在面板完整退场后解除，面板持有的独立信号随后释放。没有获取或释放宿主HTTP/目录资源。

正式页面测试覆盖cookie、用户、企业分别切走450毫秒再切回，旧用户列表保持禁用、正文不变、旧键盘不恢复；另覆盖取消后恢复正常输入和直接移除页面时的资源清理。测试均使用虚构资料。

### R2：原生用户提及只缩放一次

公开装饰器在用户WidgetSpan内部使用`MediaQuery.withNoTextScaling`，姓名和宿主头像不再重复继承系统字号，由外层正文统一缩放。旧业务引用、普通正文、实体提及和公式未改。

六组实际排版对照覆盖普通文字、旧业务引用和原生用户对象的1倍/2倍字号：行高分别为32/64，原生姓名内部不再重复缩放，外层变换仍随正文倍率变化。

### R3：菜单执行时同步互斥

StableMobileToolbar增加可选实时执行查询，顶层入口点击时同步检查当前权限，重建时清理已禁用或移除的子菜单。工具栏以借用的同步执行作用域保护T/Aa/布局子按钮及格式/颜色命令，阻止等待期间已经捕获的旧回调；独立格式面板保留原行为。

正式测试覆盖同帧先点宿主动作再点T/Aa/布局，以及先开T、开始宿主动作后调用旧Todo子菜单回调。宿主Future未完成时正文不变、子菜单关闭；完成后菜单可以重新打开。没有暂停宿主自己的正文事务。
