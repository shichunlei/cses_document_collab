# text-box 手机端基础适配

日期：2026-10-26。文本框保持“部分支持”；正式块清单42种，13已适配/28部分支持/1结构支持/0未适配不变。保留任务开始时已有的 `packages/appflowy_editor/pubspec.yaml` 和未跟踪日成果JSON，未提交、安装应用或操作在线文档。

## 实现范围

- 正式 `text-box` 接入Dart/Rust协同容器树，框内段落、标题、引用、三类列表仍持有独立的Delta/Y.Text；不把正文复制到对象属性。仅允许桌面白名单文字子块，非法旧嵌套树整体占位保护。
- 添加面板提供“文本框”，可配置 `EditorKeyboardToolbarItem.textBox` 键盘直达。新建240×120矩形并进入首段；根、高亮、单列可插入，框内禁止嵌套文本框及转换为代码/媒体。
- 手机按当前可用宽度限幅显示，不写回作者宽度。基础矩形/圆角、十六进制纯色或透明填充、实线边框及CSS式文本边距可展示；固定高度内正文可滚动，纯内容预览禁用内部滚动。读取横排已保存的自适应高度缓存，但不重新测量或同步缓存。
- 公共更多菜单提供文本框设置、删除、锁及可用的段落链接/下方插入。设置使用公共底部弹窗，宽48～2000、高32～2000逻辑像素，提供白色/浅黄/透明及黑/灰/无边框选项。草稿取消不写入，应用一次字段事务；设置高度退出自适应并清除缓存，已有宽高比锁拒绝不成比例的尺寸。
- 显式外观字段独立投影和生成补丁；未修改字段不重放到权威文档，撤销后按稳定身份定位。删除保护未知后代及后代锁，末项补空段落；原生历史可恢复完整已投影子树及原始共享数据。
- 框内列表使用平面层级、原生回车和既有行首退格边界保护；正文仍走共享输入/格式/历史服务。设置观察权限、锁版本、宿主、节点及属性快照，撤权往返或远端外观变化永久作废旧草稿。
- 新JSON导入使用正式容器；显式清除的属性不会被原始bc字段复活。旧本地 `snapshot-text-box` 的渲染/导出入口继续保留，不自动迁移旧节点到新设置操作。FRB接口未变化，未手工修改生成文件。

## 版本与桌面对照

按桌面 `.npmrc` 查询latest=0.11.31，发布产物SHA-512匹配。桌面声明/Yarn锁0.11.30、实际安装0.11.17、历史pnpm锁0.2.78，本轮未升级桌面依赖。读取随包技能L0/块指南、MIGRATIONS、Schema、规范化及对象格式/子树实现；三版文本框Schema和规范化函数SHA-256一致，见[版本证据](blockcraft-version.json)。

桌面安装包仍旧，latest整包直接导入受桌面旧 `@cses/ui` 缺少 `CsColorPickerPanelComponent` 导出阻塞。因此夹具生成器直接执行实际安装0.11.17的完整Schema工厂，并逐字核对其文本框Schema与0.11.31相同；未声称执行了0.11.31完整运行时。夹具包含富文本、扩展属性、审计数据和非法旧嵌套，生成真实Yjs update；结果见[来源](fixture-generation.json)。0.11.31与既有版本的其他对象、选区、动画、输入等差异沿用原待办，本轮不声明全版本兼容。
