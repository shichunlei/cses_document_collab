此结果未列为本轮新增缺陷：`formatCollabParagraphSelection`在HEAD与当前源码完全相同；发布版0.11.30的`getSelectionCoveredBlockIds`包含末端块，`getFontScaleTargets`将非折叠范围的空段`start=0/end=textLength=0`视为完整段落，`syncParagraphTextDefaults`同步其默认格式。这是已有段落标记语义，并非新字距菜单独自扩大范围。新行高命令则显式排除零偏移末端，已有测试锁定其行为；若要统一两类命令的段落边界政策，应另行确认并覆盖已有格式操作，不将该探针的假设直接当作新增回归。
