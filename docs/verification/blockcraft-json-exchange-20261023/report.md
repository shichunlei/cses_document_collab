# 今日导向与桌面 BlockCraft JSON 双向交换

日期：2026-10-23。

## 已实现的入口

今日导向右上角 JSON 菜单包含“导出桌面JSON”和“打开桌面JSON”。导出捕获已完成输入事务的实时正文，不读取500ms去抖之前的磁盘稿；桌面转换和文件编解码在后台完成，系统文件框写入两空格缩进UTF-8。普通桌面JSON使用无封面/栏目装饰的文档视图，不额外输出今日导向标题。打开桌面根快照后创建账号分区中的独立草稿并进入新编辑页面，原日记及所选源文件不被覆盖。取消/失败保留原文，文件框期间暂停事务，异步返回复核页面、会话和账号。

标准转换在协同包的 `BlockCraftJsonCodec`，今日导向的栏目、日期和业务转换在宿主 `JournalBlockCraftCodec`。独立内存编辑器不创建WS、SQLite或原生协同文档。任务/会议/KR详情继续借用已有、绑定账号的宿主只读服务，不根据JSON创建任务、派单或通知。

## 实际转换规则

- 每个桌面块转换为原生节点和实际后代树，文本成为原生Delta；图像/音视频、公式、代码、表格、链接及业务引用复用正式渲染组件。图片题注保留为独立富文本叶子。
- 分栏、单列、形状/内部文字、文本框、艺术字、组合/定位布局、内容区域、任务列表、天气/日期/人员卡片和思维导图增加原生转换/渲染路径。没有“不支持块+原始JSON”的保留兜底；未知插件类型、错误nodeType、重复输入ID或无法识别的行内对象直接拒绝整次导入。
- 独立属性转换到 `bc.p:<key>`、元数据转换到 `bc.m:<key>` 的本地字段，每项用值包装区分显式null和缺失，不保存原始块JSON或整篇旧快照。重导出从当前原生树读取文字、格式、状态和属性。既有 `CollabResource` 等正式组件仍使用其原有属性载体。
- 字符格式使用既有a:/s:/t:协议：bold/italic/underline/strikethrough/code、字色/背景、字号、上下标均映射；0xAARRGGBB转换为CSS并保留alpha，系统缩放不写入字号。额外桌面字重与行内对象独立转换，未知额外字符字段也不会因普通格式操作被整段重放。
- U+FFFC原生用户对象恢复为 `{mention: name}`，保留ID、类型及额外身份属性；每个对象只占一个UTF-16位置。普通“@姓名”不会伪造身份。原始引用属性中的旧样式不会在用户清除格式后重新出现。历史guidance_mention的用户/部门引用也保留身份和名称。
- 普通待办checked布尔值映射为0/1。带guidance_entry=task的普通业务行导出为todo，并记录来源类型，桌面勾选后回手机更新guidance_done。原生todo同时有业务属性时，两套状态分别保存。help/pilot的类型、条目ID及done不被合并或变成后端任务ID。
- 栏目转换为带版本化 `meta.mobileGuidance` 的标题与正文；记录日期、时区、草稿身份及创建/修改时间保留。关闭栏目也转换为标准块后保存在恢复信息中，不进入可见正文。桌面修改过的栏目标题文本/属性被保留。现有v2草稿向后兼容。
- 块ID表独立保存在草稿顶层 `blockCraftIds`，不混入原有正文业务属性；重开恢复运行时身份。插入副本分配新身份，保留移动操作身份。导入文档的锁元数据保留，锁定祖先/后代的破坏性编辑被拒绝。

## 当前明确限制

此次完成块树/字段转换和原生内容渲染，不等于桌面全部视觉与操作能力一比一复刻。形状自定义路径、预设及文字、对象位置、基本外观和文本可转换；高级几何手柄、动画、阴影/发光、渐变、艺术字路径变形和完整对象编辑工具未覆盖。原属性已转换到独立模型字段，不能将“数据保留”宣称为这些效果均已渲染。

天气/人员卡片的定格数据能显示；纯实时配置依赖宿主数据源，当前不新增实时天气或人员目录查询。任务列表的已存条目可显示，其完整筛选/分页/多视图及业务写接口未实现。任务/会议/KR详情依赖原账号服务及权限，本轮没有真实业务接口验收。

桌面新增mind-map的v2快照通常只有graphId/referenceDocumentId，完整图内容在独立Vectra文档中。当前将引用转换为原生引用卡片；包含显式树数据时渲染原生树。独立Vectra内容拉取/二进制图更新恢复和完整图形编辑尚未实现，不能称为完整思维导图适配。这是源JSON不包含图正文的边界，不能用空白图或原始JSON冒充内容。

HTTP媒体资源继续依赖原URL及权限，桌面blob/file资源不会因为转换而自动获得可移动的文件内容。未新增iOS构建、真机系统文件框或真实在线双端验收；没有改动原生桥接接口，不涉及FRB重新生成。

## 版本与范围

本轮在桌面项目按配置仓库实时查询latest=0.11.30，下载发布包并核验SHA-512；桌面根声明/Yarn锁初次核对为0.11.28，结束复核已由桌面既有工作更新至0.11.30；实际安装仍0.11.17，历史pnpm锁0.2.78。本任务未修改桌面依赖，记录外部变化0.11.28→0.11.30。读取安装版、声明版缓存及最新版随包L0、数据/适配指南、MIGRATIONS及受影响实现。最新版新增组合内容域、图片gap和斜杠菜单触发/查询/IME等机制不在本次JSON交换的完整兼容声明中。已检查Schema/属性、块与行内对象、选区/菜单、剪贴板、输入、历史及协同的受影响范围，除本轮快照与字符转换外均沿现有移动链路，差异待同步/验收。

0.11.30在本机直接运行受旧UI peer缺少CsColorPickerPanelComponent影响；临时取得所需UI包的请求遇ECONNRESET。本轮桌面运行校验使用真实安装的0.11.17，最新版只做静态产物对照，未伪装为桌面已升级或新版运行验收。版本、源码指纹和差异见[version-verification.json](version-verification.json)。

桌面注册清单增加mind-map，当前正式清单42种。新增原生JSON路径使原未适配项成为“部分支持”；正式协同路径的旧缺口仍分别保留，不把独立JSON转换当成WS/历史/菜单全链路完成。详见[适配表](../../block-adaptation.md)。

日志归档仅去除终端输出行尾空格；测试结果、失败信息及验证范围保持。提交前复核生产文件SHA-256与最终验证记录一致。
