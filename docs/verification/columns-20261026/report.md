# columns / column 手机端适配

日期：2026-10-26。范围为共享包、离线/正式编辑器及其宿主消费者；保留开始时已有的 `packages/appflowy_editor/pubspec.yaml` 和未跟踪的日成果 JSON，未提交或安装应用。

## 实现范围

- `columns`、`column` 接入正式 Dart/Rust 投影与实际子树，不再依赖新导入时的 `snapshot-*` 对象外壳。旧已落盘 `snapshot-columns` / `snapshot-column` 的原有渲染入口保留；它们不自动迁移为新结构操作对象。
- 分栏保留桌面 `columnCount`、`columnWidths` 和可选 `columnIndex`；未知共享属性及元数据不随正文/布局操作重写。读端按实际列数和正比例展示，缺失、异常或极端比例只在显示时均分，不自动落盘修复。窄屏横向滚动，每列至少约180逻辑像素；320、390、900宽度及320宽/1.8倍系统文字回归覆盖。
- 添加面板提供“多栏布局”，默认两列；可选 `EditorKeyboardToolbarItem.columns` 支持键盘直达。`EditorBlock.columns` 同时授权内部 `column`，受限文字场景不因新增入口而开放分栏。
- 公共块操作面板提供末尾添加、平均分配和“转为上下排列”；每列提供右侧插入、向左/向右移动、加宽此列（从相邻列转移5个百分点，相邻列至少保留10%）、删除此列及内容。最多8列，删除两列中的一列时将剩余内容展开；上下展开保留全部实际后代及稳定身份。相同比例设置不产生空历史。
- 列内正文继续使用原生段落/列表输入、格式及独立子块。增加列首退格保护，列表转换与回车保留列父级；公式、日期、人员、天气、会议、实体转卡片及绘图的既有插入/删除合同允许单列父级。
- 布局字段使用独立显式补丁和稳定目标；远端属性回放不回送，结构改变仍沿用既有路径历史失效策略。创建新组使用独立协同身份，列移动和上下展开保留后代身份。正文/布局/结构支持原生历史及SQLite保存重开，FRB签名没有变化。
- 正式树在写入前校验父子类型、1～8个实际列、字段取值及显式布局与子树一致性；校验按线性计数处理。非法旧树作为不透明整体保留。锁、后代锁、未知后代、只读、已关闭对象及菜单撤权往返拒绝结构操作；共享锁守卫继续处理隐藏后代锁。
