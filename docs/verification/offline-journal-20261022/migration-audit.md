# 宿主业务迁移与动态能力审查

核对日期：2026-10-22。本文记录本轮通用接口、真实控制器回归和只读审查；不替代整页、构建或真机证据。

## 职责边界

今日导向的页面、栏目协议、业务行、人员目录、选人、草稿和保存策略由宿主 `lib/src/daily_guidance/` 持有。原日记模块迁出后，宿主只通过 `cses_document_collab.dart` 使用编辑器能力，不导入协同包内部实现。

本轮仅为宿主自定义正文开放三个通用入口：

- `EditorInteractionShell` 组合既有划词菜单和键盘工具栏，借用正文与滚动资源；不配置业务模型、纸张或栏目。
- `handleDocumentParagraphEnter` 委托原段落输入链，保留段落格式与撤销语义。
- `applyDocumentBlockShortcut` 委托原块转换命令；实际正文和历史变更仍受宿主事务保护。

以上新增实现和命令测试不含今日导向业务标识。`DocumentEditorView` 未因此增加业务配置。

## 验证依据

1. 先完成原固定三栏功能的纯迁移，再添加动态能力。迁移基线共 **50 项通过**，见 [迁移基线日志](migration-v1-tests.log)，包含原页面、行线、列表对齐、粘贴与删除边界、草稿控制器和真实文件存储回归。
2. 通用公开命令 **2 项通过**，见 [公开接口测试](editor-public-api-tests.log) 和 [目标静态检查](editor-public-api-analyze.log)：宿主自定义容器内拆分保留格式并可撤销；块转换遵守能力限制并可撤销。
3. 新增动态控制器 **16 项通过**，见 [动态控制器测试](dynamic-controller-tests.log) 和 [目标静态检查](dynamic-controller-analyze.log)。这些测试使用生产控制器、真实 AppFlowy 事务、撤销/重做和独立序列化的存储快照。

动态回归实际覆盖：

- 新草稿仅显示今日记录，感悟/自检按添加顺序出现、不重复；首次添加可单独撤销和重做。
- 关闭栏目后正文与格式保留在草稿中；撤销、保存重开、恢复均保持内容。
- 句内引用替换捕获的段内范围；按 `type:id` 去重，保留同 ID 的人员与部门两种引用；名称快照和类型保存重开不丢失，不保存组织子树。
- 引用插入及重做后光标位于引用之后、原后缀之前；文字、引用和格式支持撤销/重做。
- 普通原行转换为一条待办时保留富文本；感悟内可添加待办、都来帮和领航员，都来帮/领航员各新增一行。
- 三种业务行按回车后返回普通段落，不继承业务属性；回车可撤销和重做。
- 编辑、修改日期、换会话或关闭后，旧选人目标不能写入。
- 裸对象、未知行内属性、无效引用及在普通文字上附加引用属性均被原子拒绝；同时验证块属性替换和原生文字事务两条路径。
- 总引用上限 500，关闭栏中的引用同样计入；关闭栏中的文字和叶子数同样计入字符/块容量。

## 审查发现与修复依据

- 首次添加栏目原先被“栏目身份集合只能增加”的检查阻止撤销。移除该限制、保留最终结构校验后，新增的首次添加撤销/重做用例通过。
- 人员引用插入曾把光标移到段尾：`Delta.addAll` 共享可变 `TextInsert`，拼接原后缀时使临时 `mentions.length` 增长。实施方在拼接前捕获长度后，首插和重做光标断言均通过。`Node.delta` 从序列化值重建，`Delta.slice` 也新建操作，因此该临时别名未直接改写原正文或既有历史。
- 引用在模型中只占一个位置，增加每个引用 1024 UTF-8 字节、全文 500 个引用的校验，避免仅按模型字符计量失去文件容量边界；关闭栏纳入同一预算。

额外只读审查已反馈给主实施：粘贴同样应提前捕获前缀长度；首次 v1 备份需要临时文件完整写入后再改名，防止失败留下的半份备份被下次重试信任；选人退场需要完整核对所属页面/会话、退出状态和目录账号。最终修复与对应文件回归以本轮总实施记录为准，本文不将这些反馈自动视为已验证通过。

## 限制与未通过尝试

曾单独添加人工挂载/禁用/卸载 `EditorInteractionShell` 的 Widget 用例。其测试回调完成，但 Flutter harness 在收尾阶段持续等待，手动终止后报告未完成；该尝试不算通过，重复用例已移除。实际正文包装使用原两层组件组合，其编辑/预览效果由上述原页面迁移基线覆盖。

本审查没有安装 Android 包、操作真机或验证真实企业接口。组织查询、待办/求助/领航提交等服务端结果不能由内存控制器用例证明。本地业务行和本地完成状态不等同于已创建服务端任务或通知用户。
