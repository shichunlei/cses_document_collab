# 日记列表标记垂直对齐

2026-10-22，按用户截图修复独立日记中待办框、编号和圆点偏上的问题。

原因：日记正文使用16号字、2倍行高，实际首行高32；AppFlowy默认列表标记使用22的最小高度，编号还会移除首尾行高。因此标记中心高于日记正文第一行中心。

修复：日记通过现有iconBuilder扩展点提供三种标记，使用与正文相同的32×字号缩放首行高度。编号采用与正文一致的行高和首尾行高规则，圆点/待办框在该首行高度内居中；多行正文不改变标记的垂直位置。保留连续编号及首项number设置、待办蓝色/灰色状态与原组件的勾选事务；勾选图形使用已安装lucide_icons_flutter 4.0.1的check图标。编辑和只读预览共用相同渲染。

修改范围：新增`journal_list_markers.dart`、接入`journal_surface.dart`，增加`journal_list_markers_test.dart`。未修改AppFlowy fork、其他编辑页面或保存协议，其他工作区改动保留。
