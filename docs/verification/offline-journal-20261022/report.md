# 独立离线日记实施与验证

日期：2026-10-22。

## 交付范围

新增独立 `LocalJournalPage`，首页入口为“离线日记 · 日期与横线记录”；保留原离线编辑及模板选择页面。日记包含记录日期、今日记录、感悟、自检，支持段落、平铺列表、待办、加粗/斜体/下划线/删除线、会话内撤销重做和只读预览。

- 三个栏目位于同一份本地文档中。栏目语义键和顺序固定，标题不进入可编辑正文。事务层拒绝栏目删除/重排、根级插入、删除最后一个叶子、未知块和行内对象；文字输入使用局部增量校验，结构操作在独立副本预演后原子提交。
- 横格从实际文字渲染对象的行框绘制，不生成分割线节点、占位换行或下划线字符。默认字号16、行高32；将系统字体缩放显式传给编辑器，保持文字、实际横线及空白补行相同尺度。栏目至少留三行书写空间，内容增长后向下推动后续栏目。
- 空白补行只在未发生明显移动的点击时聚焦末段，正文点击与滚动手势不被拦截。预览使用独立文档快照及相同渲染器/日期/纸张，关闭正文交互，保持滚动。
- 日期保存为YYYY-MM-DD，创建/修改时间使用UTC，创建地时区偏移单独保存；重开不会用当天日期替换旧日期。日期通过行内日历修改，不新增弹窗。
- 本地协议显式保存schemaVersion及templateId/templateVersion，使用不可变正文序列化快照。`JournalStore`由宿主注入并借用，页面/会话拥有编辑器、预览、监听和定时器。
- 500毫秒去抖、进入后台保存、退出前等待保存共用串行队列。每次写入绑定修订号，慢写入期间的新编辑继续保存，旧写入完成不能将新内容标为已保存；失败保留内存内容和旧文件，提供重试，正常退出在保存失败时留在原页。
- Demo宿主按公司/账号哈希分区，使用应用私有文件、后台编解码、同目录临时文件flush后rename。损坏或未知版本的草稿不会自动被空记录覆盖。当前每个账号恢复一份草稿，没有按日期归档的日记列表；每次启动新的编辑会话不恢复旧会话的撤销栈。

## 问题与修复记录

1. 首轮设备测试样本有18个UTF-16单元，但选区/候选范围写为20，尚未进入编辑器提交即被Flutter断言拒绝。修正测试范围后设备流程通过。保留[首次失败](android-first-attempt.txt)，不归因于生产正文丢失。
2. 布局测试发现编辑器默认不会自动采用MediaQuery缩放，且默认行高配置会覆盖文字样式；统一textScaleFactor、lineHeight及首尾行高度后，两种宽度/缩放均通过。
3. 预览保持外层滚动，仅对正文关闭指针交互；空白区域点击移至渲染层单独命中，避免抢走文字光标或在拖动结束时误触发键盘。
4. 正常应用安装后仅清理首页DartDoc示例中误产生的重复import，无行为改变；最终源码另行静态分析与正常APK重建，不再次中断设备上的日记编辑。

## 版本、边界与剩余范围

本轮通过桌面项目配置仓库实时确认 `@ccc/blockcraft latest=0.11.27`；桌面根声明/Yarn锁为0.11.24、实际安装0.11.17、历史pnpm锁0.2.78。复核对应随包技能、MIGRATIONS、日期卡片/内容区域工厂及段落装饰边界；发布产物完整性证据和先前方案见[版本核对](../offline-journal-design-20261022/report.md#blockcraft版本核对证据)。未升级桌面依赖。最新右键菜单/只读链接/UI peer等原差异仍待对应兼容验收。

本地三栏节点不是正式桌面协议，不发送给协同服务。移动 `render-unit` / `date-card` 的未适配状态保持，41种块及13已适配/14部分支持/1结构支持/13未适配统计保持。没有修改Rust、FRB、平台配置或旧离线页面；同工作区的选择性历史原型及其他既有改动由原任务继续维护，本轮不清理或纳入本功能结论。

当前尚未覆盖iOS真机、真实物理输入法候选面板操作、系统强杀前尚未落盘的去抖内容、断电级文件系统持久性或跨设备同步。正常退出会等待保存，异常终止只能恢复已经成功提交的快照。图片/表格/复杂媒体、折叠栏目、日记列表和导出不在本轮实现范围。
