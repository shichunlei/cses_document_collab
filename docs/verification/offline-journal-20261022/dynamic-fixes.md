# 今日导向引用输入与剪贴板修复

日期：2026-10-22。对应[动态引用审查](dynamic-review.md)中的P1、P2；保留原始失败探针与历史结论。本轮不修改草稿格式、账号路径、迁移备份或用户文件。

## 修复行为

- **P1，含@的复制/剪切**：宿主将已校验的人员、部门引用展开为可读的`@姓名`纯文本，与普通文字、换行一同写入系统剪贴板；重新打开页面后仍能粘贴姓名与说明。粘贴结果为普通文字，不保留实体身份或富文本格式。裸U+FFFC、未知实体与非法格式仍拒绝，不通过放宽校验绕过问题。
- 键盘复制/剪切和移动划词菜单共用宿主入口。协同包仅增加可选`EditorCommandContext.copySelection`通用委托；委托完成后不重复写剪贴板或删除，未配置的消费者沿用原行为。
- 剪切先完成剪贴板写入，再复查正文修订、选区、编辑权限与生命周期。写入失败、等待期间修改正文/格式、移动或清空选区、进入预览、撤权或关闭均保留源文；选区或权限恢复后也不能恢复旧操作。临时监听由本次操作持有，在成功、失败和关闭后的所有路径移除。
- 剪切独立封闭历史项，可一次撤销/重做。展开后超出单次粘贴容量时不删除；同一栏目内支持多段，跨栏目复制/剪切继续拒绝，保护栏目结构。
- **P2，@旁输入/替换**：在宿主事务保护入口归一化真实输入。仅在当前单段输入范围、继承身份与相邻/选中真实引用相符时，移除新普通文字的`guidance_mention`；保留加粗等基础格式、原对象及其他属性，随后继续完整模型与容量校验。支持中文合成替换；同步重建逆增量，撤销/重做不污染对象身份。
