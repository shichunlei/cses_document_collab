## 已实施的动态内容

- 新草稿只有今日记录。感悟/自检由用户点击添加，按添加顺序显示，各最多一个；业务身份使用稳定栏目语义键，操作不依赖固定0/1/2下标。
- 关闭可选栏目把完整节点保存到根草稿属性，不占可见正文空间或选区，也不进入预览；再次添加恢复原文。添加、关闭、恢复均为单次可撤销事务，首次添加的撤销/重做也有回归。今日记录不可关闭；普通退格/删除不能跨栏目合并。
- 工具栏或键入`@`打开宿主组织选择器。接入当前企业`/Company/readAllChildren`，保留真实部门树和ID，支持钻取、面包屑、搜索及人员/部门多选。按`type:id`去重，部门整体引用不展开成员；一次确认生成一组引用。
- 行内引用保存真实类型、ID及名称快照，每个占一个模型位置；未知属性、裸对象或超限引用拒绝，保留原文。单引用序列化值最多1024字节，整篇含关闭区最多500个引用，仍受原文字/块总容量和磁盘4MiB上限约束。
- 待办、都来帮、领航员为宿主可写业务行，所有可见栏目共用。现有普通正文转待办保留原文；都来帮/领航员新增一行。待办用圆环和本地完成状态，另外两种使用黄/蓝标签；业务行回车后继续普通正文，不复制人员/种类/完成状态。
- 选人前捕获会话令牌、节点身份、段内选区与修订；弹窗期间冻结正文，退场后核对页面、账号及会话。取消、权限撤销、账号切换、迟到请求或目标变化不能覆盖正文。
- 保留同源编辑/预览、日期左对齐和大写英文月份、真实文字行线及首行列表对齐。引用由外层统一缩放，长名在单行省略，避免大字/长姓名撑坏行距。

## 旧草稿与保存保证

路径继续使用原应用私有`local-journals/<原companyId:userId或local-demo的SHA-256>.json`，未改变账号分区算法。

v2读取兼容原v1、`ruled-daily`模板：保留原身份、记录日期、创建时间、时区、正文及格式。非空可选栏目原顺序可见；只有全空普通段落且无其他属性的可选栏目迁入关闭区，内容仍保存。此隐藏行为属于动态版升级，不冒充纯迁移的视觉不变。

首次覆盖v1前，将原始字节通过临时文件flush/rename提交到`.json.v1.bak`。已有备份不匹配时保留它，并另存带内容指纹的`.bak`；不把部分备份当作完整恢复依据。备份失败阻止正式升级，正式提交失败也保留旧文件；原读取失败/未知版本不会新建空稿覆盖。编解码及旧版检查在后台执行，同一存储实例只进行一次旧版备份检查；保存仍500毫秒去抖、串行且退出前等待。

具体覆盖：原始v1字节完整备份、身份/日期/文字/格式等值、全空栏目关闭区恢复、备份临时写失败后重试、已有部分备份、正式临时文件失败、不同账号隔离、损坏记录拒绝覆盖。
