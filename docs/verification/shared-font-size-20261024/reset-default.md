# 恢复默认字号

日期：2026-10-24。承接[横向字号菜单](horizontal-menu.md)，补齐选择字号之后的恢复默认操作。之前菜单只有数值，缺少取消覆盖入口。

## 当前操作与语义

选中文字后打开Aa→字号→默认；仅放置光标时，默认作用于后续输入。默认项与返回箭头固定在左侧，滚动数字后仍可直接点击，操作后菜单保持打开。

默认不是强写16像素：同一事务清除局部`t:px`及旧`s:fontSize`覆盖，继承当前段落/标题的字号。全段选择同步清除相关textDefaults中的字号，保留标题级别、颜色、加粗、字体及其他独立格式；现代t:fs等独立倍率不因该操作清除，旧s:fontSize整体按局部字号覆盖处理。光标恢复不改写已有文字，之后输入不再沿用先前显式字号。

默认状态单独回显，混合字号不误选中默认或数字；恢复支持独立撤销/重做，沿用权限、会话与支持范围校验。新入口复用原有公共格式和输入命令，不新增业务依赖或修改Rust/FRB接口。
