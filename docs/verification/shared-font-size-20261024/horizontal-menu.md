## 当前交互与边界

- Aa点击字号后在原菜单行显示数字选项，左侧返回箭头固定，只有数字区横向滚动；不新开字号底部弹窗，也不因进入字号而收起键盘。
- 选择即时写入、回显当前字号，保留菜单以连续选择；返回恢复文字样式菜单。混合或继承字号不误选某个预设；自定义字号集合继续读取实例配置。
- 划词格式面板也切换同一字号子菜单，不叠加第二张底部弹窗。颜色选择及其他原有操作保持。
- 点击时读取实时选区，支持后续输入格式与所选文字，和颜色类操作一样可跟随用户重新选择文字。连续字号修改分别封存历史；旧弹窗的跨路由回传已消失，不保留打开菜单时的旧文字范围来覆盖当前选区。
- 借用的命令上下文用于拒绝跨会话写入；打开期间撤权即使恢复也作废旧菜单，须返回重开。等待事务时阻止重复字号选择；权限监听在换文档和卸载时成对迁移/注销，不接管正文资源。

实现位于编辑器工具栏，不复制编辑核心；删除不再使用的showEditorFontSizeSheet及其专属上下文参数。控件继续复用现有主题、按钮与公共格式命令，未改变t:px数据表示、原生实现或FRB生成物。包内skill及场景参考同步当前交互。
