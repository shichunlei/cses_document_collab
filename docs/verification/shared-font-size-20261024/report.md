# 离线与协同共用字号设置

本报告保留默认能力补齐阶段的实现与验证；后续按用户要求改为横向菜单，当前交互与证据见[横向菜单记录](horizontal-menu.md)。

日期：2026-10-24。范围为默认协同预设恢复公共字号入口；制图页面继续在宿主，字号配置、面板及编辑命令继续属于共享编辑器。

## 原因与修复

字号入口和面板已由公共工具栏实现：只有实例配置允许`fontSize`才展示，面板选项读取`fontSizes`。离线默认包含该格式，协同默认`EditorConfiguration.document`漏掉该格式且传入空字号列表，因此Aa菜单和展开文字样式面板均隐藏了入口。原生字号字段、渲染及同步链已存在。

修复只改公共配置：协同预设启用`EditorInlineFormat.fontSize`，两种默认预设共同引用同一私有常量，默认选项为12、16、20、24、28、32、36。继续通过原字号面板和公共段落格式命令写入`t:px`，不复制操作、不改工具栏布局、弹窗、原生实现或FRB生成物。宿主显式禁用字号或自定义字号集合的配置保持有效。
