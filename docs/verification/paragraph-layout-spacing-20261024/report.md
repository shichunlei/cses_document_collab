# 段落布局按钮间距恢复

日期：2026-10-24。范围是用户[截图](reported-spacing.png)标注的“段落布局”后半排按钮，保留当前未提交的字号功能与其他改动。

## 原因与修复

_BlockLayoutMenu的横向列表已为缩进与对齐按钮插入间隔，但块背景色、引用线条颜色及三个下一段样式按钮遗漏间隔，导致边框相贴。

仅补齐这些位置的5逻辑像素间隔，保留缩进组后10逻辑像素间隔和现有按钮顺序、选中态、禁用态、颜色、格式事务及横向滚动。没有改公共按钮尺寸、主题或业务行为。
