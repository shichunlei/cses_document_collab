# 从文档列表进入编辑器与首页延迟打开

日期：2026-10-22。改动尚未提交。

## 行为与资源边界

- 正式模式登录后，首页只准备账号服务、恢复创建记录并启动 Common 主 WebSocket。此时没有文档控制器，不请求文档详情、权限或正文，也不占用原生文档引擎。恢复到 completed 的创建记录同样不会自动打开文档。
- 删除 `csesDemoDocumentId`、`initialDocumentId` 和首页直接进入协同编辑器的按钮。协同编辑页只能由“文档列表”路由推入；离线本地编辑入口仍独立可用。
- 文档行支持点击、打开进度及失败重试。普通打开先核验服务端访问权限，再串行释放旧文档并恢复所选文档；不建档、不生成空白正文、不覆盖创建恢复记录。
- 同一已初始化文档复用控制器，保留选区和撤销历史；复用同样核对账号并经过协调器操作锁。其他文档以只读方式恢复缓存，独立读取权限后再开放编辑。
- 列表打开与新建共享操作锁，重复点击不会打开多个文档或误拿另一个任务的返回 ID。首页的列表入口也防止重复回调堆叠路由。
- 新建成功后刷新当前空间列表，再从列表推入编辑页；返回时保留列表及所选空间。新建结果在列表被其他路由覆盖时完成，不会跳转或关闭其他页面，仍允许从右上角打开已创建结果。
- 页面退出后不回写或导航；账号关闭等待在途任务并阻止迟到的访问或权限响应重新打开文档。切换文档保留账号主连接；没有文档时也能手动重连和执行前台连接恢复。

## 接口与版本依据

参考客户端 HEAD `235b0073bd`、Java HEAD `9b0b673e1a`，未修改这两个仓库。`POST /doc/document/view` 接收 `id`；Java `DocumentQueryHandler.read` 加载文档并通过 `Action.access` 授权后返回详情，同时发布读取行为事件。打开预检只接受明确业务成功且返回 ID 与请求一致的结果，失败保留当前文档。编辑能力仍由现有 `/doc/permission/read` 链路确认。

通过桌面配置的 npm 仓库查询 `@ccc/blockcraft@latest` 得到 **0.11.27**；桌面声明 / Yarn 锁定 / 实际安装为 **0.11.24 / 0.11.24 / 0.11.21**。复核安装版及 0.11.24、0.11.27 发布产物的技能、迁移说明和宿主初始化相关实现。最新版中的 UI peer、右键设置及只读链接交互等差异不属于本次宿主路由改动；未升级桌面或移动端依赖，也未改变 Schema、块/行内数据、输入、选区、剪贴板、历史实现或协同协议。41 块及 13/14/1/13 状态统计保持，其他兼容待办仍以主表为准。
