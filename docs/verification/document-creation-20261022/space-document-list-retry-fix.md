## 修复行为

页面为位置加载创建唯一令牌，在首次await前安装在途门禁；同一帧重复调用已缓存的重试回调也只会发送一次请求。每次加载同步开启进度并清除旧错误，界面不再保留可重复点击的失败入口。

恢复记录和空间选项返回后，成功、失败回写均检查mounted及令牌身份；页面退出会使令牌失效。成功、失败及关闭都会释放门禁，失败后可继续重试。HTTP客户端和创建协调器仍由宿主持有，页面不释放借用资源。

同一页面不再产生可乱序完成的并发位置请求，因此旧请求失败覆盖较新成功的路径被阻断。上一项L1的恢复目标绑定保持，空间列表分页加载仍独立于创建动作。

## 新增回归

1. 初次加载失败后，同步调用同一个重试回调两次，只发送一次请求；成功后恢复空间选择及创建按钮。
2. 重试再次失败后，下一次重试同样去重并可成功，不残留加载锁。
3. 页面退出后，迟到的成功结果不回写状态。
4. 页面退出后，迟到的失败不回写状态，也不泄漏异常。

前两项在业务修复前均失败：预期累计两次位置请求，实际三次。修复后，四项新回归和原有恢复位置、未知结果处理、分页及鉴权回归全部通过；同时断言没有额外建档或正文写入。
