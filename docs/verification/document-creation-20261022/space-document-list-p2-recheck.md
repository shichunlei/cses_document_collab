## L2 / P2：并发重试的旧失败覆盖新的成功结果

位置：`lib/src/demo/document_creation/document_creation_page.dart:76–103`，关联第211行“重新加载位置”。

首次空间加载失败后，重试入口只检查创建任务busy。`_load`开始时没有将位置加载状态设为进行中，也没有在途任务去重或请求代次校验，因此连续点击可以同时发出多个空间请求。

复现顺序：初次加载失败，连续重试A和B；B先成功，页面已显示空间选择，创建按钮已启用；A随后失败，catch仅检查mounted，再将_loadError设为失败。结果是有效的空间选择被隐藏，创建按钮再次禁用，即使较新的请求已经成功。用户必须再次重试。

仓库外Widget复现已确认两次重试确实都发出了请求，并在新请求成功时验证选择器存在且创建可点击。旧失败到达后，选择器存在的断言失败。该问题不改变真实文档位置或正文，是空间加载状态的过期结果覆盖。

建议：对位置加载建立在途去重或加载期间禁用重试，并在成功/失败回写前核对请求代次，使旧结果失效。补上连续重试与响应乱序用例，验证旧失败不能覆盖新成功。
