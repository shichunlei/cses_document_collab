## 修复

恢复记录读取完成后立即将操作目标保留在页面选择状态，再等待空间选项请求。点击“继续完成”前同样绑定该操作目标。空间响应返回时保留已有选择，只补全选项；完成待导航期间不再因pending变为false回落个人空间。

即使空间请求失败，列表仍使用本次恢复位置；稍后重试也保持该目标。已有completed记录在新页面不会被当作本次恢复，仍按新入口指定位置选择。

修改范围仅为DocumentCreationPage及其Widget测试，不修改HTTP契约、创建状态机、包级API、原生数据或FRB接口。
