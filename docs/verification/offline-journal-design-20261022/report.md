# 离线横线日记与固定分区方案

日期：2026-10-22。范围：截图需求可行性与源码核对；尚未实现或进行功能验收。

## 结论与现状

可在现有 Flutter 离线编辑器上扩展。建议使用一份结构化文档，包含固定日期头部、今日记录、感悟和自检分区；各分区内容按正常文档流增长，共用输入、选区、格式、撤销与预览。

- `LocalEditorController` 继承 `DocumentEditorController`，持有内存中的 AppFlowy 文档，不创建 SQLite、网络或原生协同会话；现有构造器仅接受初始纯文本。当前入口不具备草稿持久保存和恢复能力。
- `ImageComposerController` 和 `ImageComposerPage` 已有编辑/独立快照预览、外观模板选择；`CollabImageTemplate` 仅配置渐变、边距、圆角，不承载分区结构和日期。
- `DocumentEditorView` 已有随文档滚动的 header/footer，但未提供固定分区和横格配置。`AppFlowyRichText` 内部持有实际文字的 `RenderParagraph`；行线应基于真实文字布局扩展，不能另建不同参数的排版器后假定位置一致。
- 移动适配清单中 `render-unit`、`date-card` 均为未适配。此次方案不改变这两行状态或既有41种块、13/14/1/13统计。

## 建议交互

1. 顶部使用淡粉标题区、米白纸张和日期组件，展示记录日期、星期，可选显示创建时间。日期默认为新建当天，允许显式修改；重开旧日记不滚动到今天。
2. 今日记录支持段落、无序/有序列表、待办和基本文字格式。感悟、自检各默认保留三行视觉书写空间，输入后自动增高，将后面的分区向下推动；不固定绝对坐标或内部滚动高度。
3. “固定”按栏目身份、标题和顺序固定理解，内容可以编辑。栏目外壳不能经退格、剪切、跨区删除或块转换意外破坏；这需要独立的结构保护规则，不复用会让后代正文一起只读的协同块锁。
4. 截图的“关闭”建议定义为折叠/展开，保留内容且可恢复；删除栏目作为另一个明确操作。空白最小行数是绘制留白，不向正文填充占位换行。
5. 点击空白书写区聚焦该区可编辑段落。栏目边界处理回车、退格、跨区选区与粘贴，不允许输入路径绕过结构保护。预览隐藏光标和编辑按钮，保留相同纸张、日期、栏目和行线。

## 行线实现

横格是展示层，不生成 divider 节点或下划线字符，不进入复制内容和正文撤销历史。

- 首期建议字号16逻辑像素、行距约32逻辑像素、浅米色细线、左右20逻辑像素留白；这些是设计起点，需窄屏与大字实测。
- 普通文本、列表和待办按实际布局行的底部位置绘制通栏横线，背景绘制不得接管命中或遮挡选区。空白最小书写区补齐装饰横线。
- 字号、系统文字缩放、宽度、行内对象或内容改变后重新布局并局部重绘。若使用固定行距网格，必须将段间距、列表间距也约束到网格；不得仅给整个页面画等距背景便宣称每行对齐。
- 图片、表格、公式等首期不进入横格分区；后续可按普通内容块保留自然高度并在其后恢复行线。标题和卡片区不强制套正文横格。

## 数据与职责

- 一份本地日记记录保存 `schemaVersion`、`templateId/templateVersion`、稳定日记ID、记录日期及记录时区、UTC创建/修改时间、分区稳定身份、折叠状态和结构化文档快照。字段是拟议本地协议，并非现有公开API或BlockCraft正式字段。
- 分区以稳定ID/语义键识别，不靠“感悟”标题文字或节点数组位置匹配；正文始终只存在一份文档树中。切换外观模板保留正文，结构变化需显式迁移与字段匹配。
- 新增经校验的快照恢复入口，检查版本、节点类型、容量与分区结构后创建会话。结构保护在事务提交前统一执行，覆盖菜单、键盘、粘贴、撤销重做，原子拒绝破坏外壳的操作。
- 自动保存由独立本地草稿存储端口负责，存储实现通过宿主注入。保存任务按日记ID与修订序号串行、原子写入；可采用约500毫秒去抖，退出时等待最后一次保存。失败展示未保存状态并保留可重试内容；不得显示“已保存”后实际只留在内存。
- 页面/会话创建者负责监听、去抖和控制器释放；关闭前等待在途保存，切换日记或销毁后旧异步回调失效。大快照编解码和文件写入按实际开销放后台。
- 第一阶段使用本地模板结构。后续若需要与桌面互通，应先适配正式 `render-unit`、`date-card` 及日期物化/字段协议，再增加本地模型到正式快照的映射；不能将自定义本地结构直接发送给桌面。

## 实施顺序与验收

1. 完成日记结构、稳定栏目身份、日期和草稿存储/恢复；保护固定外壳，同时保留子内容正常编辑与撤销。
2. 扩展实际文本布局的行线绘制，接入纸张主题、栏目最小留白、折叠和同源预览；首期只开放文本、列表、待办及基本格式。
3. 验证中文输入法候选提交、自动换行、空栏目、跨区退格/剪切/粘贴、撤销重做、折叠恢复、窄屏/大字/键盘遮挡、滚动与预览一致性。
4. 验证保存失败、乱序任务、退出保存、重新打开、异常终止恢复、日期跨天与时区变更；退出完成前保存和异常终止仅能恢复已持久化版本应分别说明。
5. 如纳入桌面互通，再覆盖Schema/属性、块与行内对象、选区/菜单、剪贴板、输入、历史与协同链路及双端持久化恢复。媒体/业务卡片离线可用性独立验收。
