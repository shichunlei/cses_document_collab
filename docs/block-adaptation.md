## 更新规则

1. 适配能力或限制变化时，同步更新对应清单、统计、核对日期和更新记录；记录能力变化、验证结果及剩余限制。
2. 状态以实际功能为准：仅有菜单、占位或数据保留不算已适配；未完成的功能标为“部分支持”或“适配中”，并注明缺口。
3. 桌面块新增、移除或重命名时，核对基础注册、页面追加注册及模板物料，更新清单与总数。
4. 提交前确认文档与代码一致，保留无关工作区改动。
