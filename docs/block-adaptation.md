# 桌面块移动端适配表

最后核对：2026-10-13。桌面依赖：`@ccc/blockcraft` 0.11.14。

本表记录 CSES 桌面主文档编辑器实际注册的块及其在本项目移动端的适配情况，作为后续适配工作的统一清单。每完成一个块的适配，须在同一次改动中更新本表。

## 统计与口径

| 状态 | 数量 | 含义 |
|---|---:|---|
| 已适配 | 8 | 已支持表中列出的展示、编辑或交互及正式文档同步能力；不代表已覆盖所有桌面属性 |
| 部分支持 | 8 | 仅在指定场景下支持，或仍缺少独立编辑能力 |
| 结构支持 | 1 | 已支持文档底层结构，不属于用户直接插入的内容块 |
| 未适配 | 24 | 尚无对应的正式块适配；占位展示不算完成适配 |
| 合计 | 41 | 基础注册 40 种，文档页面初始化时追加任务列表 1 种 |

未适配块统一显示不可编辑的占位卡片，原始共享内容、属性和子树完整保留；它们不会使整篇文档只读，其他已识别块仍可编辑和同步。包含占位块的父容器不可整体删除。该容错展示不计入“已适配”，本表状态与数量不变。

H1～H9 是 `paragraph.props.heading`，不另计为块类型。行内链接、@提及、行内公式等不计入本表。移动端自有的独立链接、封面和文档标题也不计入桌面块数量。

资源添加面板统一独立保存原光标/选区和块 ID，打开后正文失焦并暂停输入；确认按原块位置插入，关闭动画结束后恢复正文输入，取消则恢复原选区及方向。协同重排按块 ID 重新定位，原块删除时停止插入并提示重选；嵌套面板全部关闭前不恢复正文焦点。此交互修正不改变下表状态统计。

## 移动端自有块

以下能力已在移动端 Demo 中实现，但没有隐式的桌面正式块映射，不能算作对应桌面块已适配。

| 名称 | 移动端类型 | 范围 |
|---|---|---|
| 独立链接 | `link` | URL 同步及打开链接；不等于 `bookmark` 或 `embed` |
| 文档封面 | `document_cover` | 离线 Demo 的固定头部封面；底部面板支持图片链接与本地上传，关闭后恢复原正文选区 |
| 文档标题 | `document_title` | 离线 Demo 的固定头部标题；不同于段落 H1～H9 |

## 更新规则

1. 每完成一个块的适配，在同一次代码改动中更新对应行的状态、支持范围和剩余限制，不留到后续任务。
2. 状态以实际实现和验证结果为准。仅增加菜单入口、占位展示或保留未知原始数据，不标为“已适配”；功能尚不完整时标为“部分支持”或“适配中”，并写明缺口。
3. 同步更新统计数量、最后核对日期，并在下方更新记录中注明块名、能力变化及验证依据。
4. 桌面新增、移除或重命名块时，重新核对基础注册、页面运行时追加注册和模板物料注册，更新清单与总数。
5. 相关适配变更提交前，确认本表已同步更新；不因文档更新额外要求提交与该块无关的工作区改动。
